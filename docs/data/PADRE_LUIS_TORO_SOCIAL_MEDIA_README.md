# Padre Luis Toro public social-media discovery layer

This data captures publicly discoverable metadata only. It is intentionally not an exhaustive Facebook or Instagram archive, and it does not imply account affiliation beyond the platform-level labels shown in each record.

Use social posts chiefly to discover a full source, a debate, a short Q&A, or a platform-specific title. When a fuller original video exists, retain the social post as a provenance lead and prefer the original source for study review. Do not publish a source-derived claim, quotation, transcript, doctrinal mapping, or attribution until a reviewer verifies the underlying material.

Instagram is retained as a profile lead only in this release because reliably reusable individual-post metadata was not available during the bounded public scan.
